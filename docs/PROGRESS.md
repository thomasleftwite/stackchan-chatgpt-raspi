# Raspberry Pi移植の進捗

更新: 2026-10-23。主要機能を実装・実機確認し、次回は残項目を完了してリリース候補の準備へ進む。PR #6〜#12をmainへ統合済み（機能統合HEAD `7dfe58d`）。正式リリースはまだ作成していない。

## 完了した機能

- Pi専用GUI/CLI、有線インターネットと端末用Wi-Fi AP、Piからの端末WiFiManager設定、APへの復帰。
- ホスト開始/停止/再開、声のプルダウン、次の質問への声変更、端末通信/会話/再生モニター。
- 端末スピーカーでの固定サンプル試聴、採用/除外、複数の声の保存/選択、アプリ再起動後の復元。
- APIキーのPi内AES-256-GCM暗号化保存、次回起動での復元、更新/削除。ローカル暗号鍵の保護範囲は [Piアプリ](../raspi/README.md) に記載。
- 既存端末のHTTP/WS・PCM仕様を使用。端末ファーム・呼びかけ登録の変更なし。Windows製品コードの変更なし。

## 確認できたこと

- 利用者が通常の呼びかけからの音声回答、2回の回答と声の変化、端末での試聴・採用保存を確認。
- GUIを別プロセスで再起動してキー/採用声の復元、試聴ウィンドウの再表示3回を確認。
- 複数声が消えたとの報告は、保存2件と一覧3項目を保持していることを件数で確認。停止中のfixtureでも一覧を開けるよう修正後、利用者も▼から既定と複数候補が出ることを確認。
- 端末再起動後のAP参加・DHCP・fixtureホスト到達、実APでのfixture開始/停止、プロセス回収とポート再利用を確認。
- 自動回帰はNode54件成功、Python139件中135成功・Windows専用4件スキップ。最終の統合前実行結果は [検証記録](VALIDATION_PLAN.md) を参照。

## 継続する制約

端末ファームを変更せず、有線インターネットを維持する。実機ネットワーク/遠隔管理/systemd設定の変更は事前計画・復旧手順・明示承認の対象。外部API課金を伴う検証を自動で行わない。資料に秘密値、音声、声名など個人設定を含めない。
