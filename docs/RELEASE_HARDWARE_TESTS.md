`scripts/validate_ap_recovery.py`の引数なし実行は計画表示のみ。承認後の`--execute`で、wlan0だけを180秒のNetworkManager checkpointで保護し、既存APを5秒停止して元の接続へ戻す。有線eth0・既定経路・SSH/Connect・プロファイル内容は変更しない。復帰確認後にcheckpointを確定し、明示復帰に失敗した場合はrollbackを要求する。プロセスが中断された場合も180秒のdaemon側rollbackを残す。元のAP設定・パスワードを読み出し表示しない。
