# Raspberry Pi Host 0.1.0-rc.1

公開前のリリース候補。Raspberry Pi 5 / Debian 13 ARM64向け。Windows Hostの版番号とは別に管理する。

- 既存端末ファームのままGemini Liveの1質問1回答を中継。
- 声選択、開始/停止、端末通信モニター、端末での試聴/採用/除外、複数声の保存/復元。
- APIキーの暗号化保存・起動時復元・更新/削除。
- 固定Nodeと本番依存を同梱。ユーザー領域への導入・更新・旧版復帰、手動起動用ショートカット、秘密値を含まない診断。

起動は手動。初期状態はAPI不要の接続確認モードで無音応答。自動起動、systemd変更、ネットワーク設定変更、ファーム書込みを自動で行わない。

最終テスト結果、実機再起動・障害復旧・Windows互換性の合否は公開前に[リリース準備](RELEASE_READINESS.md)と[検証記録](VALIDATION_PLAN.md)へ記録する。未実施の項目を成功扱いしない。正式版公開の判定は実機確認後に行う。

暗号鍵もPi内で所有ユーザー専用に保管するため、同一ユーザー/rootやディスク全体流出から保護する方式ではない。通常ホスト稼働中の試聴、Windowsブラウザーへの音声転送、多ターン会話は今回の範囲外。

利用者指定により通信断・Pi本体再起動の実機試験は後日実施する。今回は未検証として扱い、正式版の安定性保証の根拠にしない。WindowsネイティブのNode/Python CIは合格しているが、端末を接続したWindows PCでの実音声とは区別する。
